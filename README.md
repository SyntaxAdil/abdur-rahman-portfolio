## ✨ Features

- **📐 Responsive Design** — Mobile-first layout that scales beautifully across all viewports
- **🎞 Framer Motion** — Smooth scroll animations & micro-interactions throughout
- **📮 EmailJS Contact** — Powered form with Zod validation & React Hook Form
- **🔍 SEO Optimized** — Metadata, Open Graph tags & semantic HTML structure
- **⚡ 95+ Lighthouse** — Blazing fast load times with Next.js image optimization
- **♿ Accessible** — WAI-ARIA compliant components for inclusive UX

## 🔐 Environment Variables

Create a `.env.local` file in the root directory:

```env
NEXT_PUBLIC_EMAILJS_SERVICE_ID=your_service_id
NEXT_PUBLIC_EMAILJS_TEMPLATE_ID=your_template_id
NEXT_PUBLIC_EMAILJS_PUBLIC_KEY=your_public_key
```

## 🚀 Getting Started

### Installation

```bash
# Clone the repository
git clone https://github.com/SyntaxAdil/abdur-rahman-portfolio.git

# Navigate to project directory
cd abdur-rahman-portfolio

# Install dependencies
npm install
```

### Available Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start development server with hot-reload |
| `npm run build` | Create optimized production build |
| `npm run start` | Run production server locally |
| `npm run lint` | Run ESLint for code quality checks |
| `npm run type-check` | Run TypeScript type validation |
